## Install · 安装

Each public mod has a zip on its Releases page that already includes BepInEx. Unzip it into the game folder, next to the game's `.exe`.

公开的 mod 在各自的 Releases 页面有安装包，已带 BepInEx。解压到游戏目录，和游戏的 `.exe` 放在同一层。
